# 用語集

| 用語 | 意味 |
|---|---|
| **SPH** | Smoothed Particle Hydrodynamics。流体を**粒子**で表し、近くの粒子の寄与を**カーネル**で足して、密度や力を求める方法 |
| **カーネル** | 距離に応じた重み。`Poly6`(密度)・`Spiky`(圧力の勾配)・`Viscosity`(粘性のラプラシアン)を使い分ける |
| **平滑化長(`h`)** | カーネルの届く半径。空間ハッシュのセルの大きさも、これに合わせる |
| **空間ハッシュ** | 空間をセルに分け、セルの番号をハッシュにして、近くの粒子だけを探す仕組み。全ペアの O(N²) を、平均 O(N) にする |
| **状態方程式(EOS)** | 密度から圧力を決める式。ここでは `p = max(k(ρ − ρ₀), 0)` |
| **静止密度(`rest_density`, ρ₀)** | 圧力が 0 になる密度。これより詰まると、押し返す |
| **Symplectic Euler** | 先に速度を更新し、**新しい速度**で位置を更新する積分。ふつうの Euler より、エネルギーが安定する |
| **Stable Fluids** | Stam(1999)の格子法。移流に**セミラグランジュ**を使うので、大きな `dt` でも発散しない |
| **セミラグランジュ移流** | 各格子点から、速度で**逆にたどった**位置の値を補間で取る方法 |
| **射影(projection)** | 圧力で、速度場の**発散を消す**(非圧縮にする)操作。ポアソン方程式を解く |
| **赤黒(Red-Black)** | 格子を市松模様に塗り分け、同じ色どうしを同時に更新する反復。並列化しやすい |
| **FLIP / PIC** | 粒子と格子の混合。PIC は格子の速度をそのまま、FLIP は格子の**速度の変化**を粒子に足す。`alpha` は PIC の割合 |
| **P2G / G2P** | 粒子 → 格子、格子 → 粒子 の転送 |
| **MAC グリッド** | 速度を、セルの**面**に置く格子(圧力は中心)。非圧縮の計算が安定する |
| **カールノイズ** | ノイズの**回転(curl)**を速度場にした、発散ゼロの流れ。**物理は解かない**見た目用の近似 |
| **発散(divergence)** | 速度場が、その点から湧き出す量。**非圧縮の流れでは 0** |
| **状態ハッシュ** | 状態の配列(`float64`)のバイト列の SHA-256。**1 ビットでも違えば別**になる |
| **監査ログ** | 設定のハッシュ・NumPy の版・シード・ステップごとの状態ハッシュを持つ JSON |
| **サンドボックス実行** | 検証 + タイムアウト + 再現性の記録 を付けて、ソルバーを動かす(`run_simulation_sandboxed`) |
| **Neural Fluid(GNN)** | 粒子の近傍をグラフにして、次の状態を学習する方法(`neural/`) |
| **WebAssembly(WASM)** | C++ の SPH を、ブラウザで動かす形にしたもの(`wasm/`) |
| **`frames.json`** | Viewer の入力。`metadata`・`frames`(粒子の座標)・`speeds` を持つ |
| **プリセット** | `gen_sample.py` の、初期配置と物性の組(`water_drop`・`smoke`・`splash`) |
| **物性テスト** | 運動量・質量・境界など、**成り立つべき性質**を確かめるテスト |
