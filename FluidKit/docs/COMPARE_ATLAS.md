## 3. 読み方の注意

- **格子法 (Stam)** は気体向けの密度場で、空気側も非圧縮として解くため、水塊は自由落下せず遅れる。質量比が 1 から大きく外れる (密度が保存されない) 原因は未調査 (圧力投影の残差・移流の補間・境界処理が候補)。
- **SPH** の壁は反射のみ (床の斥力なし) で、着地後は粒子が床に押しつぶされる。
- **SPH / FLIP** は粒子数が一定なので質量比は構成上 1.0。保存するかどうかを見るには運動量・エネルギーを見る。
- ms/シミュ秒は時間刻みの違いを吸収したコスト。SPH は陽解法のため小さい刻みが要る。
- いずれも学習用の簡易実装の値で、**物理的に厳密ではない**。手法の性格の比較として読むこと。


## 4. カールノイズと格子法 (Stam) — 軽さと物理らしさ

カールノイズは「ノイズの回転を速度場にする」だけの擬似流体 (圧力も保存則も解かない)。同じ単位正方形で、Stam (64×64 格子, 圧力投影あり) と比べる。

| 項目 | 格子法 (Stam) | カールノイズ |
|---|---|---|
| 1 ステップの時間 | 1.15 ms (格子全体。コストは格子数で決まる) | 2.06 ms (4096 粒子の移流, RK2。コストは粒子数にほぼ比例) |
| 速度場の発散 (最大) / 速度勾配 rms | 1.91e-01 / 2.57e-01 = 7.40e-01 | 3.57e-05 / 2.10e+00 = 1.70e-05 |
| 発散ゼロの根拠 | 圧力投影を 20 回の反復で近似 (残差が残る) | 解析的に ∇·(∇×A) = 0 (差は離散化誤差 O(h²) のみ) |
| 解いているもの | 近似的な非圧縮ナビエ–ストークス | なし (ノイズの回転) |
| 壁・障害物 | あり (no-slip) | なし (粒子を反射させるのは別処理) |
| 外力への応答 | あり (重力や衝撃に反応する) | なし (入力に反応しない) |

読み方: コストは Stam が格子数、カールノイズが粒子数 × 波の数で決まる。この条件では約 2282 粒子より少なければカールノイズの方が軽く、多ければ Stam の方が軽い (**常にカールノイズが軽いわけではない**)。カールノイズは発散が小さい「流れっぽい動き」を作れるが、外力や壁に応答しないので**物理らしさは別物**。飾りの煙や水流に向き、衝突・落下の再現には SPH / FLIP / 格子法を使う。計測値は学習用の簡易実装・この環境での一例。
