# 第 0 回 流体シミュレーションの全体像

> 所要時間の目安: 1 時間 / 前提: Python と NumPy の基本

## この回のゴール

- 流体を計算機で扱う**2 つの見方**(粒子で追う・格子で見る)と、このリポジトリの 3 つのソルバーの違いを説明できる。
- 「**速く**」「**再現でき**」「**正しい**」の 3 つを、どう守っているか(空間ハッシュ・状態ハッシュ・物性テスト)を言える。

## 1. 流体の 2 つの見方

| 見方 | 考え方 | ソルバー |
|---|---|---|
| **ラグランジュ**(粒子) | 水の**つぶ**を 1 つずつ追う。つぶが流れて動く | **SPH**(`sph_solver.py`) |
| **オイラー**(格子) | 空間を**格子**に区切り、各マスの速度・密度を持つ。流体は、その上を通り抜ける | **Stable Fluids**(`stable_fluids.py`) |
| **ハイブリッド** | 粒子で運び、格子で圧力を解く | **FLIP**(`flip_solver.py`) |

![FluidKit の構成](../diagrams/architecture.svg)

## 2. 守っていること

| 目標 | 手段 |
|---|---|
| **速く** | 近傍探索を**空間ハッシュ**(全ペア O(N²) → 平均 O(N))・NumPy のベクトル化(第 1 回) |
| **再現できる** | 設定と各ステップの状態を **SHA-256** でハッシュに残す(第 2 回) |
| **正しい** | **物性のテスト**: 運動量の保存・質量の保存・境界を貫通しない(第 2 回) |

## 確認問題

1. SPH と Stable Fluids の、流体の見方の違いは。
2. 流体のシミュレーションで「正しい」を、どう確かめますか。

## 解答

1. SPH は**粒子**を追い、Stable Fluids は**固定した格子**の上の値を更新する。
2. 厳密な答えが無いので、**保存則**(運動量・質量)や**境界を越えない**といった、必ず成り立つ性質を、テストで確かめる。

## まとめ

- 粒子(SPH)・格子(Stable Fluids)・ハイブリッド(FLIP)。
- 速さ(空間ハッシュ)・再現性(状態ハッシュ)・正しさ(物性テスト)を、それぞれ仕組みで守る。
